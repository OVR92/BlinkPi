    Email
    
    
    Used for watchdog alerts and, optionally, a message for every new clip with its thumbnail and AI summary. Gmail: smtp.gmail.com, port 587, STARTTLS, an app password.
    
    
    
    
      
    
      
    
    
    
    
    
      
    
      
    
    
    
    
    
      
    
      
    
    
    
    
    
    
      
    
        
    
      
    
    
    
    
    Attaching clips turns your mailbox into a simple cloud backup: each clip is a few MB. Mind your provider's limits (Gmail: 25 MB per message, roughly 500 messages per day on personal accounts, 15 GB storage).
    
    
    
  
    
  
    
    
    Webhook
    
    
    POSTs a JSON document to a URL for each event: new clips (camera, filename, path on the SMB share, AI description) and watchdog alerts. Works with Home Assistant webhook triggers, Node-RED, n8n, ntfy, ...
    
    
    
    
    
    
  
    
  
    
    
    Watchdog
    
    
    Checked after every sync pass. Alerts go to email and/or webhook. Each condition alerts once, then again after the reminder interval, and sends a recovery message when it clears.
    
    
    
    
      
    
      
    
    
    
    
    
      
    
      
    
    
    
    
    
    
  
    
  
    
    
    AI clip summaries
    
    
    Extracts frames from each new clip with ffmpeg and asks a vision model to describe them. The description shows in the clip browser and in notifications. Works with any OpenAI-compatible endpoint: OpenAI, OpenRouter, Groq, Gemini, or a local Ollama / LM Studio (free). Pick a model that accepts images. Home Assistant users can instead point LLM Vision at the clips on the SMB share via the webhook.

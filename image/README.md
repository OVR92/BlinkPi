# BlinkPi SD card image

A ready-to-flash Raspberry Pi OS Lite (64-bit) image with BlinkPi
pre-installed. No SSH, no editing YAML: flash it, boot it, join the
setup hotspot, click through.

## Using the image

1. Flash `BlinkPi-<date>.img.xz` with **Raspberry Pi Imager**. Skip the
   OS customisation dialog (or use it to preset Wi-Fi - that works too and
   you then skip step 3).
2. Boot the Pi Zero 2 W. Give it about a minute.
3. If the Pi finds no network it broadcasts a Wi-Fi hotspot:

   | | |
   |---|---|
   | SSID | `BlinkPi-Setup` |
   | Password | `blinkpi123` |

   Join it from a phone or laptop. The setup page opens automatically
   (captive portal); if not, browse to **http://10.42.0.1/**.
4. On the **Network** tab pick your home Wi-Fi and enter its password
   and your 2-letter country code. Your device drops off the hotspot
   while the Pi joins your network.
5. Rejoin your own Wi-Fi and open **http://blinkpi.local/**.
6. **Storage** tab: enable an SMB share and/or an rclone remote
   (create remotes on the **Cloud** tab - Google Drive, Dropbox, S3,
   B2, SFTP, WebDAV, ...). Press **Apply**.
7. Plug the Pi's **USB** port (not PWR) into the Sync Module 2. In the
   Blink app go to *Sync Module → Local Storage* and tap **Format**.
8. **Settings** tab: set an admin password for the setup page.

Ethernet (via a USB adapter) works too: the Pi then just appears on
your LAN as `blinkpi.local` and never raises the hotspot.

Default SSH login is `blink` / `blinkpi`. Change it with `passwd`.

### Fallback hotspot behaviour

The setup service watches the network. If the Pi has no IP address for
60 seconds it raises the hotspot. While the hotspot is up it drops it
every 5 minutes to retry the saved Wi-Fi, and brings it back if that
fails. You can disable the hotspot on the Network tab.

## Building the image

Requires Linux (or WSL2) with Docker. Takes 30-90 minutes the first time.

```bash
git clone https://github.com/OVR92/BlinkPi
cd BlinkPi
./image/build.sh                 # -> image/deploy/BlinkPi-*.img.xz
WPA_COUNTRY=DE ./image/build.sh  # preset the Wi-Fi regulatory domain
```

The build uses [pi-gen](https://github.com/RPi-Distro/pi-gen) (arm64
branch) with one extra stage, `image/stage-blinkpi`, which:

- installs the apt dependencies (`00-packages/00-packages`)
- copies the project to `/home/blink/BlinkPi` and creates its venv
- enables the `dwc2` USB gadget overlay so no reboot is needed after setup
- adds the captive-portal dnsmasq rule for the hotspot
- enables `blink-setup.service` (the setup page, port 80)

Everything else (gadget, sync, wipe, prune, web UI units, sudoers,
fstab) is generated by `scripts/install.sh` when you press **Apply**
on the setup page - the same installer manual installs use.

Set `USE_DOCKER=0` to build natively on a Debian host with pi-gen's
dependencies installed.
